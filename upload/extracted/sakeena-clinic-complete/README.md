# سكينة — Psychiatric Clinic Management System (Complete Project Bundle)

Full delivery bundle: backend source, integrated frontend source, test report, and all
screenshot evidence from the end-to-end verification runs.

## What's inside

| Path | Contents |
|---|---|
| `backend/` | Express + Prisma + PostgreSQL + Socket.io API (the existing backend — unmodified source of truth) |
| `frontend/` | Vite + React 19 app (Figma-exported design preserved, fully integrated with the backend) |
| `test-results/screenshots/` | 67 screenshots — initial deep pass + regression run #1 |
| `test-results/final-regression/` | 54 screenshots — final clean regression on a freshly reset database |
| `TEST_REPORT.md` | Full feature checklist, workflow results, financial audit figures, known limitations |
| `worklog.md` | Implementation log (integration decisions, backend-contract realities, fixes) |
| `scripts/` | `start-backend.sh` / `start-frontend.sh` helper scripts |

## Requirements

- Node.js ≥ 20
- npm (backend) and pnpm (frontend)
- No external database needed — the backend boots a **disposable embedded PostgreSQL**
  via `qa-boot.mts` (auto migrations + seed). Never touches any persistent/production DB.

## Quick start

```bash
# 1) Backend (API on http://localhost:4000, base path /api/v1)
cd backend
npm install
npx prisma generate
QA_INFO_PATH=./qa-info.json npx tsx qa-boot.mts
# (Linux/macOS: set QA_INFO_PATH to any writable path — connection info for the throwaway DB)

# 2) Frontend (dev server on http://localhost:3000, proxied to :4000)
cd ../frontend
pnpm install
PORT=3000 pnpm dev
```

Or use the helper scripts from the bundle root (adjust the `/home/z/my-project` paths in
them to your extraction location first):

```bash
bash scripts/start-backend.sh
bash scripts/start-frontend.sh
```

## First login (seeded credentials)

| Field | Value |
|---|---|
| Identifier | `doctor` |
| Password | `ChangeMe123!` |

- The seeded doctor account has `passwordMustChange: true` — you will be forced to rotate
  the password on first login.
- Create the secretary account from the doctor side: **الإعدادات والمستخدمون → حساب استقبال جديد**.
- Roles: DOCTOR (full clinical + administrative) and SECRETARY (front desk: check-in,
  queue, payments, receipts, intercom, closing, display).

## Notes

- `node_modules/` are intentionally excluded (regenerated by `npm install` / `pnpm install`
  from the included lockfiles: `backend/package-lock.json`, `frontend/pnpm-lock.yaml`).
- The AI scribe module runs with mock adapters by default (no external API credentials).
  The manual SOAP documentation path is fully functional.
- Run the backend's own test suite anytime: `cd backend && npm test`.
- The demo passwords used during testing (`Sakeena2026!` / `SakeenaSec2026!`) belonged to
  the disposable test database and no longer exist; a fresh boot re-seeds `ChangeMe123!`.
